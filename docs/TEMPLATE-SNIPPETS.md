# 模板布局动态片段

模板 HTML 布局的任意位置（包括 head）可引用片段名称：

```html
<head>
  <meta charset="utf-8">
  [[include:test]]
</head>
```

引用名区分大小写，仅支持英文字母、数字、下划线和连字符，与现有正文引用语法一致。
生成时展开片段源码，再执行一次完整模板。片段内可使用布局相同的数据变量，例如
`{{.title}}`；不要假设布局上下文中存在正文片段渲染器的 `{{.Title}}`/`.Data` 对象。

- 预览/旧渲染路径读取片段库；正式发布从发布规划时冻结的 snippet map 读取，
  不在历史快照重渲染时查询当前数据库。
- 相同片段可重复引用；嵌套最多三层。缺失片段、循环引用或超深嵌套会报错，
  不发布未展开的布局标记。原正文 include 行为不变。
- 不绕过模板原有脚本策略。需要插入 script 的片段，仍需当前发布的冻结策略允许。
- 修改片段后不必修改引用它的模板，但必须重新生成/发布受影响文章。Cloudflare
  已部署的静态 HTML 不会在访问时读取片段库，需重新导出并部署。
- `src="aaa"` 是相对脚本地址，不代表实际资源存在；请换成真实可访问的地址。
- 本次代码改动未自动修改九套线上模板、片段内容或任何已发布文章。
